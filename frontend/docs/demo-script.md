# StoryWeaver 三分钟 Demo 脚本

本脚本只展示当前真实前端能力。自动录屏使用确定性 Playwright 数据；连接真实后端时使用同样页面路线。

## 录制

```bash
pnpm demo:record
```

视频、Trace 和截图位于 `artifacts/demo`。测试数据只存在于 `tests/e2e/fixtures/demo.ts`，不会进入生产构建。

## 三分钟路线

### 0:00—0:35 登录与项目

1. 登录文脉；
2. 进入“青铜城行动”；
3. 展示作者意图、当前焦点和已确认的“青铜城”正典资产；
4. 说明 Token 只保存在当前页面内存中。

### 0:35—1:20 创作工作台

1. 从左侧进入创作工作台；
2. 创建本地 Writing Block；
3. 打开 Writing Block Canvas 并输入片段；
4. 打开真实正典资产 Canvas，引用选区到 Composer；
5. 明确说明后端没有 Chat/Conversation API，因此没有假回复或假会话历史。

### 1:20—1:50 世界书

1. 进入世界书；
2. 展示关键词、优先级、作用域、可见性和向量开关；
3. 说明激活调试查询没有业务 Controller，不展示伪造检索结果。

### 1:50—2:30 章节工作流

1. 进入章节和 TipTap 编辑器；
2. 展示 IndexedDB 草稿恢复、正式版本和写前预检；
3. 连接真实后端时可继续展示 Workflow SSE、停止/恢复、Review 和审批；自动录屏用已有 Phase 4—7 E2E 分别验证这些流程。

### 2:30—3:00 模型与费用

1. 进入模型与费用；
2. 展示 Token、Cache、费用、请求耗时和模型能力；
3. 展示版本化项目预算和未计价请求边界；
4. 结束时指出所有数字来自后端，测试 Demo 数据不进入生产。

## 与设计稿原 Demo 的差异

设计稿包含新建/搜索持久化会话、Chat SSE、AI 打开人物卡、方案回复和 Chat 内联 Diff。后端当前没有相应 API，这些步骤被明确排除，不能在录屏中冒充已实现。
