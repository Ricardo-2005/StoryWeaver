# Phase 1 完成记录

## 已实现

- 登录、注册、仅内存 Bearer Token、`GET /api/me` 当前用户缓存。
- 未登录路由保护与 401 自动清理会话、返回登录页。
- 项目列表 Loading/Empty/Error/Retry、新建、详情、全量更新、归档和快照。
- 正典资产列表、创建、更新不可变版本、确认和废弃。
- ChatGPT 式左侧框架、真实项目切换、项目搜索、顶部项目栏、移动端抽屉导航。
- 统一 400/401/403/409/422/429/5xx Problem Details 展示。
- 浅色、深色与跟随系统主题。

## 契约限制

后端没有 Conversation/Session/Chat API，因此“新对话”明确禁用，最近会话区域显示契约缺失说明；没有本地伪造会话、AI 回复或计时器模拟。

项目卡没有展示设计稿要求的总字数、当前章、BLOCKER、工作流状态和累计费用，因为 Project API 不返回这些字段。新建项目也只提交后端真实支持的五个字段，没有伪造多步骤资产或预算保存。

## 测试覆盖

- API Bearer Header 与 401 Hook。
- Problem Details 状态和字段错误规范化。
- 项目全量 PUT 与 `expectedVersion`。
- 登录、注册、项目创建、正典资产创建、401 返回登录、移动端导航。
