# Phase 2 完成记录

## 已实现

- 人物：空白创建、基础字段编辑、当前状态编辑、生命状态与位置。
- 世界书：创建、编辑、启用、常驻/向量开关、关键词、优先级、作用域与可见性。
- 大纲：MASTER/VOLUME/ARC/CHAPTER 节点创建和编辑，父节点与顺序字段，Tree 上下方向键焦点移动。
- 章节：章节骨架创建、标题和章纲编辑；不启动 Workflow 或 SSE。
- Skill：BASE/PROJECT/CHAPTER 规则创建和编辑，`key=value` 输入校验与真实合成预览。
- 所有更新提交 `expectedVersion`，409 使用统一 Problem Details 呈现。
- 项目侧栏增加人物、世界书、大纲、章节和 Skill 入口。

## 后端契约限制

- 人物没有自定义字段、Progression、Mentions、合并或历史接口。
- 世界书没有删除、树结构、拖动、移动、复制、历史接口；激活调试器保留契约说明，不伪造结果。
- 大纲没有删除、批量排序、移动、拆分、合并和历史接口，因此不提供假拖拽。
- 没有字段级 AI 候选接口。
- 章节正文版本 API 已建类型和 endpoint，但本阶段页面只维护章节骨架，SSE 写作留给后续阶段。

## 测试

Playwright 覆盖人物、世界书、大纲、章节和 Skill 的空白创建，验证世界书必填字段自动聚焦及大纲方向键操作。
